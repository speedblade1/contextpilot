- Publisher preview now supports selecting a registered publisher and country.

## AI integration

`apps/api/src/ai/openai.ts` uses the OpenAI Responses API with strict function calling, `store:false`, bounded output, a 30-second per-attempt timeout and two SDK-managed transient retries. The model is configurable; the default is `gpt-5.4-mini`, verified against the official model documentation. There is no automatic fallback that impersonates a real LLM.

The strict output contains all eight field keys; null means unchanged. Zod validates all non-null fields, then trusted campaign services check publishers, ownership, state and revisions. Activation still requires the user's dedicated confirmation action.

The application handles missing credentials, authentication failure, quota/rate limits, unavailable models, timeouts and malformed/incomplete responses with safe messages. API keys and raw upstream errors never appear in the browser. Configuration status means a key exists, not that it has been successfully verified. **Check OpenAI connection** performs an actual small structured-response request; it does not save a campaign. The equivalent CLI command is `npm run ai:check`.

A key was added privately during implementation. A live connection check reached OpenAI but returned HTTP 429 (quota/rate limit), so a successful completion has not yet been verified. Review the API project billing/usage limits and use Check OpenAI connection afterward. Tests inject fake SDK responses and explicitly isolated deterministic fixtures; they do not substitute for a successful live provider request.

## Local data and limits

The API binds to loopback. The fixed internal owner identifier is retained for compatibility with existing campaigns; it is not a user account. User names and motion preferences are saved in this browser's local storage. Campaign data lives in SQLite.

The local publisher preview is an actual working SDK consumer, not a claim of an external partner relationship. Your website must integrate the SDK and be able to reach the API. This computer-bound setup is not publicly deployed. Budgets remain planning values, with no payments or purchases. Five countries and USD are supported as before.
